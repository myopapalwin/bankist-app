## Bankist Project

## Description

A banking application built with Vanilla JavaScript using
MVC architecture,
ES Modules and JSON Server.

This project was created to practice production-like frontend architecture before moving to React.

## Features

- User Login
- Transfer Money
- Loan Money
- Close Account
- Account Summary
- CRUD Operations
- Form Validation
- Error Handling
- Loading State
- API Integration

## Tech Stack

- HTML
- CSS
- JavaScript (ES6+)
- ES Modules
- JSON Server
- Git
- GitHub

## Installation

Clone the repository

```bash
git clone https://github.com/myopapalwin/bankist-app.git

# JSON Server Start

cd bankist-api
npm install
npx json-server db.json

# Frontend Start
use Live Server
   (or)
bankist-app/index.html
```
